Library Management System 📚
A SQL-based library system with books, members, borrowings, fines, and categories.

📦 What's Inside
Books, Members, Borrowings, Fines, and Categories tables
Triggers for borrowing and returning logic
Queries for overdue tracking and book categorization
🛠️ How to Use
Import library_management_system.sql into MySQL
Run the file to set up your database
